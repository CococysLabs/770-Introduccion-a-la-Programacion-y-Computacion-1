# Ejemplos - Segundo Semestre 2026
**Curso:** Introducción a la Programación y Computación 1 (Código: 770)  
**Ciclo:** Segundo Semestre 2026 (2S2026)

Este directorio contiene los ejemplos prácticos y proyectos de demostración desarrollados durante el ciclo, organizados según la práctica o proyecto correspondiente.

---

## 📁 Distribución del Material

### 📌 [Básicos](./Basicos/)
- **Ejemplo0**: Configuración inicial y guía de entorno.
- **EjemplosBasicos**: Sintaxis básica y conceptos fundamentales de Java en consola.

### 📌 [Práctica 1](./Practica%201/)
- **SistemEstacionamiento**: Sistema de control y cobro de parqueo implementado en consola con Programación Orientada a Objetos (POO), manejo de matrices/vectores y lógica de tarifas. Incluye enunciado original.

### 📌 [Práctica 2](./Practica%202/)
- **Ejemplo1Practica2**: Demostración de hilos (`Thread`) en Java, colisiones y entidades gráficas básicas en Java Swing (nave, proyectiles, enemigos).
- **Practica22S26**: Implementación completa de juego espacial aplicando arquitectura Modelo-Vista-Controlador (MVC), generador de enemigos con hilos concurrentes y panel gráfico en Java Swing.
- **SnakeP2**: Clásico juego de Snake desarrollado en Java Swing con control de hilos para animación en tiempo real, manejo de récords y menús gráficos.

### 📌 [Proyecto 1](./Proyecto%201/)
- **CentroRescate**: Aplicación de escritorio completa en Java Swing con patrón MVC para la gestión de un centro de rescate animal. Incluye registro de animales, filtrado por categorías, panel administrativo y generación de reportes HTML.

### 📌 [Proyecto 2](./Proyecto%202/)
- **Ejemplo6**: Implementación de estructuras de datos dinámicas lineales desde cero (`ListaSimple` y `ListaDoble` con sus respectivos nodos) visualizadas mediante paneles interactivos en Java Swing.
